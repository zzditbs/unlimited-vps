## “不限流量”限的到底是什么？先算端口这笔账

总量不设限，速度封顶——这就是“不限流量”（unmetered）的真实含义。商家不对流量总量计费，但你的传输速度被端口带宽卡死。这笔账不难算：**100Mbps 端口的理论上限是每月 32TB 左右**（12.5MB/s 连跑 30 天），500Mbps 大约 162TB，1Gbps 大约 324TB。对个人站、小团队业务来说，这个上限平时根本摸不到。

真正要留意的是三件事：

- **端口速度决定日常体验**。同样是“不限流量”，200Mbps 和 1Gbps 的大文件下载速度差五倍。
- **出向流量才是大头**。流量计费主要算的是服务器发出去的数据，一个有点访问量的网站、一台自用代理或者媒体服务器，一个月跑几个 TB 很正常。
- **看清流量那一栏的写法**。写 Unmetered 才是不限流量；写"4 TB included""3 TB/月"的是计量制套餐，超量后按 GB 收费或直接限速。两类套餐经常被商家放在同一个页面上卖，下单前看仔细。

## 按用途选：谁适合不限流量，谁该去买计量制

月流量稳定超过 2–3TB 的场景，才真正值得上不限流量VPS：建站加图床加备份的混合用途、自用代理中转、Plex/Jellyfin 这类远程观影的媒体服务器、几个人共用的团队出口，都在这个范围里。

两类人可以划走：

1. **月流量 1TB 以下的轻度用户**。计量制年付VPS便宜得多：bytevirt 的 2核2G、1.5TB@500Mbps 一年 $35；racknerd 的 2核2G、每月 5TB 一年 $35.99；akilecloud 的美国机房甚至给到每月 10TB、一年约合 $35。这类套餐基本都支持支付宝，超量才限速或计费，轻度用户一年都碰不到那条线。

## 不限流量VPS常见问题

**不限流量VPS会限速吗？**
会，端口带宽就是速度上限。500Mbps 端口再“不限”，单连接拉满也就这个速度，选套餐时端口速度比流量字眼更值得看。

**一直跑满带宽会被封号吗？**
各家处理方式写在服务条款里，以你购买那家的协议为准。短时间大流量属于正常波动；长期不间断打满端口的用法，在任何商家那里都可能触发限制或被要求升级，部署前翻一眼条款不亏。

**自动备份要额外花钱吗？**
多数商家按套餐价的 20% 左右加收，OVHcloud 这类把备份包含在套餐里的属于少数。MKCloud 各档是否含备份，下单页会有明确标注，结账前看一眼。

**月付还是年付？**
不限流量档位建议月付起步，试错成本低，线路不合适随时换；年付低价的主场在计量制套餐，前面列的 $35/年那一批就是例子。
